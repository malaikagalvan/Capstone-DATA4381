27SEP26 (Sheehey) - The basic neural net excercise is a tutorial from Victor Zhou (https://victorzhou.com/blog/intro-to-neural-networks/). Amazing reference to see what is actually happening under the hood and the math that happens inside at least a basic neural net. The model uses sigmoid function as activation function and stochastic gradient descent in back propagation. The math can be a bit heavy if you're rusty on partial derivates. Once you've brushed up on it though it isn't too bad. The code is absolutely not optimized and for a larger dataset like ours that will require more neurons we won't want to hand craft each neuron by hand. A different approach requires a matrix form for gradient descent and neuron construction.
